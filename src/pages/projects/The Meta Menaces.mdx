## Brief

To create a 3D FPS that is set within the Meta Menaces Universe, within a designated time period

## About

This project was developed for a client called [Iconika](https://iconika.io/), and was designed to be set within the universe of their Novel, [The Meta Menaces](https://themetamenaces.io/). It is a 3D Movement FPS that is set in medievil England and entails the player navigating through a small Village, killing any guards, archers or Menaces (A shapeshifting beast that is a core foe in The Meta Menaces). Once you reach the Cathedral at the end of the level, you must fight the main villain of the Meta Menaces novel, Malachai.
